How It Works

This example demonstrates how to integrate Cloudflare Stream Player with the Video Analytics Worker:

  1. Access Played Ranges: Uses the Stream Player API's player.played TimeRanges property
  2. Extract Ranges: Loops through player.played.start(i) and player.played.end(i)
  3. Track Changes: Monitors the timeupdate event to detect new played ranges
  4. Batch Upload: Periodically sends all ranges to the analytics endpoint
  5. Visual Feedback: Shows real-time progress bar and statistics

Implementation

// Initialize Stream Player
const player = Stream(document.getElementById('stream-player'));

// Track ranges on each timeupdate
player.addEventListener('timeupdate', () => {
    const ranges = [];
    
    // Extract all played ranges from the player
    for (let i = 0; i < player.played.length; i++) {
        ranges.push({
            startTime: player.played.start(i),
            endTime: player.played.end(i)
        });
    }
    
    // Store for batch upload
    trackRanges(ranges);
});

// Periodically flush to analytics API
setInterval(() => {
    sendToAnalytics(videoId, ranges);
}, 10000);
